# 📊 Retail Sales Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive Retail Sales Dashboard built using Microsoft Excel. It transforms raw sales data into meaningful insights using Pivot Tables, Pivot Charts, Slicers, and Timeline filters to help analyze business performance.

---

## 🎯 Objectives

- Analyze total sales and profit.
- Compare sales across different retailers.
- Track sales trends over time.
- Analyze sales by region.
- Compare different sales methods.
- Build an interactive dashboard for quick business insights.

---

## 🛠️ Tools Used

- Microsoft Excel 365
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filter
- Excel Formulas
- Dashboard Design
